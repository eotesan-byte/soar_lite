# SOAR Lite - Simulador de Seguridad (SOC-SOAR)

Proyecto en fase de prototipo/desarrollo enfocado en la automatización de la ciberseguridad, análisis de logs y ejecución de respuestas automáticas (Playbooks).

## Estructura del Proyecto
- `main.py`: Orquestador principal del flujo.
- `generador.py`: Generador de eventos y registros de logs simulados.
- `analizador.py`: Motor de análisis de seguridad y generación de reportes SOC-SOAR.
- `palabras.py`: Catálogo de amenazas, palabras clave y listas de severidad.
